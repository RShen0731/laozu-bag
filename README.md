# 《我要当老祖》法宝背包摆放优化器

基于模拟退火算法的《我要当老祖》法宝背包智能摆盘与战力最大化求解工具。

## ✨ 功能特性

- **法宝全量收录**：覆盖各大武器形态与品阶法宝。
- **长老星级与觉醒统一配置**：支持设置红宝长老星级（1~5星）与法宝觉醒等级（觉醒1~5），并排设置，清晰直观。
- **觉醒羁绊支持**：
  - **觉醒1**：相邻指定系法宝每件提供自身属性加成。
  - **觉醒2**：自身基础三围（攻/防/血）+20%。
  - **觉醒3**：相邻指定系法宝强化加成（+8%）并解锁同形态法宝全局加成。
  - **觉醒4**：自身基础三围再累加 +30%（累计+50%）。
  - **觉醒5**：升级为同系相邻增益（+15%）与同系全局加成。
- **弟子天赋与权重调节**：支持 4 格弟子形态基础数值加成配置，支持战力模式与加权/乘积暴击模式。
- **多线程 Worker 极速退火求解**：支持多核并行运算，毫秒级快速得出最佳格子摆放。
- **方案保存与导出**：本地自动持久化保存配置，支持多方案切换。
