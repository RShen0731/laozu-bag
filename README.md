# 《我要当老祖》法宝背包摆放优化器 (Laozu Bag Solver)

基于模拟退火算法的《我要当老祖》法宝背包智能摆盘与战力最大化求解工具。支持全量五阶神器觉醒规则计算、长老星级增益、双行属性/类型筛选及多核极速摆放计算。

## ✨ 核心特性

1. **属性与形态双行筛选与移动端优化**：
   - 第一行属性：`属性`、`金`、`木`、`水`、`火`、`土`、`雷`、`邪`、`体`
   - 第二行类型：`类型`、`刀`、`剑`、`枪`、`乐`、`异`、`御`、`锤`、`幡`、`斗`、`珠`（单格法宝归纳为【珠】）
   - **移动端视觉革新**：拥有数量从内部文字重构为右上角绝对定位的悬浮红底白字小红点（Badge），按钮高度整齐划一，彻底杜绝手机端文字折行与高矮不齐。
2. **全量五阶神器标明专属长老**：
   - 法宝选择列表、已选列表、背包图例及悬浮详情中，所有五阶神器均自动展示对应长老名称（如 `朔气飞星 (邓婵玉)`、`金锋无影 (白虎)`、`龙渊七星 (酒剑仙)` 等），方便玩家按长老极速查找法宝。
3. **极简直观的摆盘视觉设计**：
   - **摆盘中心纯粹展示类型单字**：圆圈内只展示法宝形态单字【刀/剑/枪/珠/乐/异/御/锤/幡】，孙悟空如意金箍棒展示【枪】，单格法宝展示【珠】。
   - **高辨识度属性背景配色**：采用纯白边框、纯白文字的经典圆形徽章，针对金系（明亮金黄 `#f59e0b`）与土系（浓郁大地深褐 `#713f12`）进行专属高对比度色彩调优，告别混淆，一眼可辨。
   - 法宝列表名称旁带有形态徽章，下方图例与悬浮详情全方位直观呈现。
4. **长老星级与觉醒统一行配置**：
   - 界面极简设计，每行仅保留【法宝名称 + 长老星级下拉 + 觉醒等级下拉】，无多余杂乱元素。
5. **多线程 WebWorker 极速摆放计算**：
   - 浏览器多核并行模拟退火，毫秒级快速得出战力极高且羁绊拉满的最佳阵型。
6. **本地存储**：
   - 方案与配置自动同步至本地浏览器 LocalStorage，刷新不丢数据。
